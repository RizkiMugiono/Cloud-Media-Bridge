# Independent read-only supervision

The trusted operator may invoke `cloud-media-bridge cloud watch SESSION` repeatedly from a separately controlled host or OS scheduler. The CLI returns one JSON report and exits. `--local-only` prohibits network calls. Without that flag it checks the exact account and the recorded resource using read-only provider operations where the native adapter supports them. The command never modifies the journal or authorizes provider mutations.

Time is measured conservatively from persisted creation intent to confirmed stop (when available); it is not a provider billing timestamp. Estimated exposure uses the original approved quote's billing rounding, minimum and ancillary estimate; the true invoice can differ, and storage, network, renewal and commitments can continue. Missing, future or inconsistent timestamps and missing costs produce warnings rather than fabricated numbers. The supervisor flags uncertain create, stop, worker and transfer states, limits and scheduled-policy deadlines; manual retention is not silently converted into automatic stop.

Run under a dedicated operator identity with read-only provider credentials if available, protected session storage and independent logging/alerts. Use a scheduler on a host that remains available when the user's agent disconnects. On Linux, a systemd timer may run a oneshot service every 30 seconds. On Windows use a scheduled task under an independent service account. Configure logging, notifications, missed-run detection and service restart separately. Do not pass secrets as command-line arguments. No scheduler is automatically installed or started by the repository.

This is a read-only monitoring component, not an enforcement watchdog. A confirmed provider state is not proof of invoice cessation, active-job status or verified artifact transfer. Independent automatic action dispatch, authoritative event collection, scheduler deployment and credential isolation must be implemented/verified before the production gate can open. A hard budget cannot be guaranteed from a periodically sampled price.
